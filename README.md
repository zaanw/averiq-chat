# Averiq Chat

Интерактивный предварительный просмотр дизайна Averiq Chat для GitHub Pages.

**Важное ограничение:** GitHub Pages размещает статические файлы HTML/CSS/JavaScript, но не запускает Node.js, Socket.IO и базу данных. Поэтому этот сайт — только демоверсия интерфейса: сообщения сохраняются **только в браузере** через localStorage. Они не доставляются другим пользователям, а аккаунты не создаются. Пароли здесь вводить не нужно.

## Функции текущего предпросмотра
- Тёмная и светлая темы, настройки цвета, плотности, размера текста, отправки по Enter.
- Переключение чатов, поиск, фильтры, отправка демосообщений и сохранение данных локально.
- Адаптация под мобильные устройства.
- Демонстрационная синяя галочка у @zaan и подпись «Создатель Averiq Chat».
- Бесплатный деморежим оформления Ultra, без подписок и оплаты.

## Как включить GitHub Pages
В репозитории открой **Settings → Pages → Build and deployment**, затем выбери **Deploy from a branch**, ветку **main**, папку **/(root)**, нажми **Save**. После публикации адрес обычно будет:
https://zaanw.github.io/averiq-chat/

Если сайт выдаёт 404, подожди пару минут и проверь настройку Pages.

## План настоящего мессенджера
Для версии с регистрацией и сообщениями между пользователями потребуется сервер Node.js/Socket.IO на отдельном HTTPS-хостинге и постоянная база данных. Перед публикацией нужно настроить домен API, CORS, безопасные сессии, резервные копии, ограничение загрузок и проверку безопасности. Никогда не выкладывай в репозиторий папки данных, вложений, токены и секреты сервера.

Здесь опубликован именно предпросмотр. Ранее созданный серверный проект Averiq Chat 4.0 остаётся отдельной заготовкой для следующего этапа.
